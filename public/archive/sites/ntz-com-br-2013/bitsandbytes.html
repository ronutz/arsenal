Unidades de Medidas

 

Byte - a unidade de medida de grandeza de informações

 

1 Byte = 8 bits
1024 Bytes = 1 kiloByte
1024 kilobytes = 1 megaByte
1 kiloByte = cerca de 8000 bits (exatos 8 x 1024 = 8192 bits)
1 megaByte = cerca de 8000000 bits (exatos 8 x 1024 x 1024 = 8388608 bits)

 

bit - a unidade de medida para transferência de dados

1 kilobit = 1000 bits
1 megabit = 1000000 bits

 

Dados armazenados (em disco rígido, CDs, disquetes) têm seus tamanhos medidos em kilobytes,
porém a taxa de transferência de dados (a velocidade com que os dados são transferidos) são expressos em kilobits.

 

 

Taxa de transferência

(largura de banda, capacidade de vazão, velocidade de transferência)

 

Regra para calcular taxas de transferência:
KByte de dados transferidos / segundos utilizados na transmissão = taxa de transferência em KBytes por segundo.

Tomemos como exemplo o tempo gasto para a transferência de um arquivo:

Um modem de "56k" usa quanto tempo para transferir um arquivo de "56k"?

 

Modem de 56kbps (= 56000 bits por segundo)
Dados totalizando 56KB (=57344 bytes = 458753 bits)
458753 bits levam '?' segundos para serem transferidos a 56000 bits por segundo?

 

O modem gasta pelo menos 8,2 segundos, e não 1 segundo como poderia-se supor.
