## Was das Tool tut

Das Tool ist ein Linter für Konfigurationsobjekte von F5 Distributed Cloud (XC). Fügen Sie ein Objekt origin_pool, http_loadbalancer oder app_firewall ein, aus der JSON-Ansicht der Konsole oder aus der API, und es markiert Einstellungen, die riskant, überraschend oder wahrscheinlich Fehler sind, jede mit einem Schweregrad und einer kurzen Erklärung, die sich auf die Dokumentation von F5 stützt. Es läuft vollständig in Ihrem Browser und führt kein neues Schema ein: Jede Regel verwendet die Objektstrukturen wieder, die für die anderen Tools dieser Familie geprüft wurden.

## Was das Tool prüft

Bei einem Origin-Pool markiert der Linter TLS zum Origin mit übersprungener Serverprüfung (die Verbindung ist verschlüsselt, aber das Zertifikat des Origins wird nicht validiert), deaktiviertes SNI, Klartext zum Origin, eine fehlende Zustandsprüfung (Health Check) und einen einzigen Origin-Server ohne Redundanz. Bei einem HTTP-Load-Balancer markiert er eine fehlende WAF (Web Application Firewall), einen Listener mit reinem HTTP ohne HTTPS, HTTPS ohne Weiterleitung von HTTP auf HTTPS, eine Route, die die WAF deaktiviert, eine Catch-all-Route vor anderen Routen (die bei der Auswertung nach dem ersten Treffer nie passen können) und eine Wildcard-Domain zusammen mit ihrer Apex-Domain. Bei einer WAF markiert er den Monitoring-Modus (erkennt, blockiert aber nicht) und deaktivierte Threat Campaigns.

## Schweregrad und Grundlagen

Jeder Befund hat einen Schweregrad (hoch, Warnung oder Info), und die Liste ist so sortiert, dass die schwerwiegendsten zuerst stehen. Die Stufe „hoch“ ist Einstellungen vorbehalten, die die Sicherheit wesentlich schwächen, etwa das Überspringen der Origin-Prüfung. „Warnung“ gilt für Einstellungen, die meist falsch sind, etwa eine fehlende WAF oder eine verdeckte Route. „Info“ gilt für Dinge, die man wissen sollte, die aber oft beabsichtigt sind, etwa ein einzelner Origin. Jede Regel nennt die Quelle von F5, auf der sie beruht; eine Markierung ist daher Ausgangspunkt für eine Entscheidung und kein Urteil. Manche dieser Einstellungen sind im Kontext die richtige Wahl, und der Linter sagt, warum jede davon wichtig ist, damit Sie entscheiden können.

## Was das Tool nicht ist

Der Linter liest jeweils ein Objekt und schließt nur aus dem, was darin steht. Er kann nicht sehen, ob eine namentlich referenzierte WAF selbst im Monitoring-Modus ist oder ob ein Origin-Pool, auf den eine Route verweist, eine Gewichtung hat; das steht in anderen Objekten. Er ist ein schneller erster Durchgang über die eigenen Einstellungen eines einzelnen Objekts, kein vollständiges Konfigurations-Audit.

## Ergebnisse teilen

Unter den Befunden erzeugt **Ergebnisse teilen** einen Link auf diese Seite, und zwar nur, wenn Sie die Schaltfläche wählen. Der Link enthält nach dem `#` eine Kopie des Objekts, nie das Objekt so, wie eingefügt. Ein Objekt für Origin-Pool, Load-Balancer oder WAF kann Secrets enthalten, die der Linter nie liest. Das Schema von F5 Distributed Cloud kennzeichnet sie: SecretType, „used in an object to indicate a sensitive/confidential field“, enthält das Secret entweder im Klartext (`clear_secret_info.url`: „For string:/// scheme, Secret needs to be encoded Base64 format“) oder mit Blindfold verschlüsselt (`blindfold_secret_info.location`) ([XC-API-Referenz](https://docs.cloud.f5.com/docs-v2/api/views-http-loadbalancer), abgerufen am 01.11.2026): den privaten Schlüssel eines Zertifikats, den `secret_value` eines Headers oder Cookies, einen Client-Schlüssel für mTLS. Der einfache `value` eines Headers oder Cookies, den ein Load-Balancer hinzufügt („Exclusive with [secret_value]“), ist ebenfalls ein häufiger Ort für das Shared Secret eines Origins. Der Linter liest, welche Einstellungen vorhanden sind, und einige Namen und Domains, nie diese Werte. Deshalb ersetzt die Kopie jedes SecretType-Secret und jeden hinzugefügten Header- oder Cookie-Wert durch `[redacted]` und behält jedes andere Byte so, wie eingefügt. Bevor der Link angeboten wird, liest die Seite die Kopie erneut und muss zum selben Prüfergebnis kommen, sonst gibt es keinen Link; danach wird die Kopie nach Zugangsdaten durchsucht, die noch darin stehen (ein privater Schlüssel außerhalb von SecretType, der Wert eines Matchers für den Header `Authorization`, ein JWT, ein Passwort in einer URL, erkannt wie in den anderen Tools der Website): Findet sich eines davon, gibt es keinen Link, und das Popover nennt die Zeile; ein Wert, dessen Name nur nach einem Secret aussieht, wird stattdessen im Popover genannt.

Das Popover nennt zuerst, was der Link enthält, und bietet dann „Link kopieren“ und, sofern der Browser eines bietet, das Teilen-Menü an; die Adresse der Seite bleibt unverändert. Es nennt außerdem, wie viele Werte ersetzt wurden, und dass das Objekt seine Pools, Hosts und Domains nennt und womöglich Tenant und Namespace. Hat die Kopie nur Header- oder Cookie-Werte ersetzt (keiner davon ein `Authorization`-Wert oder einer, dessen Name nach einem Secret aussieht, und nichts sonst im Objekt Zugangsdaten), können Sie diese über einen Schalter unter der ersten Zeile, **Die ersetzten Header- und Cookie-Werte in den Link aufnehmen**, doch mitsenden: Er ist bei jedem Öffnen des Popovers ausgeschaltet; ist er aktiviert, enthält der Link das Objekt so, wie eingefügt, und das Popover warnt, dass Header- und Cookie-Werte Token oder das Shared Secret eines Origins enthalten können. Neben einem SecretType-Secret wird der Schalter nie angeboten, ebenso wenig, wenn Zugangsdaten den Link verhindert haben.

Laut [RFC 3986](https://www.rfc-editor.org/rfc/rfc3986) (Abschnitt 3.5, abgerufen am 01.11.2026) ist das Fragment „separated from the rest of the URI prior to a dereference“, also vor der Dereferenzierung vom Rest der URI getrennt; daher wird, was nach dem `#` folgt, beim Öffnen des Links nicht an den Server gesendet. Es bleibt in der Adressleiste und im Verlauf dessen, der den Link öffnet, und wer den Link hat, kann es lesen.

- **Länge.** Insgesamt höchstens 16.384 Zeichen, die Grenze, die die Website für jeden Wert nach dem `#` setzt; ist der geteilte Inhalt länger, gibt es keinen Link, und das Popover nennt seine Länge.
- **Öffnen eines Links.** Die Kopie (oder, mit dem Schalter, das Objekt) füllt das Feld wie beim Einfügen, und die Seite prüft sie. Danach verschwinden die Werte sofort aus der Adresse der Seite, ohne dass eine Anfrage gesendet wird; ein Neuladen oder die Schaltfläche „Teilen“ der Seite überträgt daher nichts.
