## Was das Tool tut

Stellen Sie einen FortiGate-Befehl `diagnose sniffer packet` aus seinen Teilen zusammen, oder fügen Sie einen vorhandenen Befehl ein, um jedes Argument erklärt zu bekommen, alles ohne ein Gerät zu berühren. Der eingebaute Sniffer von FortiOS ist das erste Tool, zu dem die meisten greifen, wenn ein Paket nicht dort ankommt, wo es soll, und seine Befehlszeile packt fünf Positionsargumente in eine Zeile. Das Tool setzt diese Zeile für Sie zusammen und liest sie Argument für Argument zurück. Es läuft vollständig in Ihrem Browser und stützt sich auf die eigene Sniffer-Dokumentation und die CLI-Referenz von Fortinet.

## Einen Befehl erstellen

Wählen Sie eine Schnittstelle (oder `any` für alle), optional einen Host, einen Port und ein Protokoll, dann eine Ausführlichkeitsstufe, eine Paketanzahl und ein Format für den Zeitstempel. Das Tool setzt den genauen Befehl zusammen:

```
diagnose sniffer packet <interface> <'filter'> <verbose> <count> <tsformat>
```

Der erstellte Filter steht in einfachen Anführungszeichen, so wie FortiOS einen mehrteiligen Ausdruck im BPF-Stil erwartet, und ein `host` und ein `proto` werden mit `and` verbunden. Ist kein Filterteil gesetzt, wird das blanke Wort `none` verwendet, das alles auf der Schnittstelle mitschneidet. Jedes Argument wird neben dem Befehl erklärt, und die üblichen Fallen werden schon beim Erstellen markiert.

## Einen Befehl dekodieren

Fügen Sie einen Befehl wie `diagnose sniffer packet any 'host 10.1.1.1 and tcp port 443' 4 0 l` ein, und jedes der fünf Argumente wird zurückgelesen: die Schnittstelle (und ob `any` einen Linux Cooked Capture bedeutet, der den echten Ethernet-Header verbirgt), der Filter und was er trifft, die Ausführlichkeitsstufe und was sie genau ausgibt, die Paketanzahl und das Format des Zeitstempels. Die abgekürzte Form `diag sniff packet` wird ebenfalls akzeptiert, und ein Befehl, bei dem Anzahl oder Zeitstempel am Ende fehlen, wird trotzdem dekodiert, denn diese Argumente sind auf dem Gerät optional.

## Ausführlichkeit, Zeitstempel und die Fallen

Die Ausführlichkeit reicht in FortiOS von 1 bis 6. Die Stufen 1 bis 3 geben schrittweise mehr vom Paket aus (Header, dann die IP-Nutzdaten, dann den vollständigen Ethernet-Frame); die Stufen 4 bis 6 tun dasselbe, geben aber zusätzlich den Namen der Schnittstelle aus, die jedes Paket genutzt hat, und genau das brauchen Sie mit `any`. Die vollständige Ausgabe auf Ethernet-Ebene (Stufe 3 oder 6) lässt sich mit dem Skript `fgt2eth.pl` von Fortinet in eine `.pcap`-Datei für Wireshark umwandeln. Das Argument für den Zeitstempel ist `a` für absolute koordinierte Weltzeit (UTC), `l` für absolute Ortszeit oder fehlt für eine relative Zeit seit Beginn des Mitschnitts; das Tool warnt, dass sich ein relativer Zeitstempel nicht zwischen parallelen Mitschnitten abgleichen lässt. Außerdem markiert es die beiden klassischen Gründe, warum ein Mitschnitt nichts zeigt: VLAN-Tags werden bei `any` und bei VLAN-Schnittstellen auf hohen Ausführlichkeitsstufen entfernt, und an die Hardware ausgelagerte Sitzungen (NP/SoC) umgehen den Sniffer im Kernel vollständig, sodass Sie während der Fehlersuche womöglich `set auto-asic-offload disable` in der passenden Firewall-Richtlinie brauchen.

## Umfang und Grundlagen

Das Tool setzt Befehlstext zusammen und erklärt ihn; es startet nie einen Sniffer, öffnet keinen Socket und ruft nichts ab, und dieselbe Eingabe ergibt immer dieselbe Ausgabe. Es bildet die Grammatik des Befehls und die dokumentierte Bedeutung von Ausführlichkeit und Zeitstempel ab; es schneidet keine echten Pakete mit und parst keine. Jede Angabe stammt aus dem Abschnitt des FortiGate Administration Guide über das Ausführen eines Sniffer-Trace, aus der CLI-Referenz von FortiOS zu `diagnose sniffer packet` und aus den Hinweisen zur Fehlersuche in der Community von Fortinet. Nichts, was Sie eingeben oder einfügen, verlässt die Seite.

## Ergebnisse teilen

Unter dem Befehlsfeld erzeugt **Ergebnisse teilen** einen Link auf diese Seite, und zwar nur, wenn Sie die Schaltfläche wählen. Der Link enthält nach dem `#` den geöffneten Modus: im Modus „Befehl erstellen“ das Formular als benannte Werte, immer jedes Feld (`iface`, `host`, `port`, `proto`, `verbose`, `count` sowie `timestamp` als `a` oder `l`, bei relativer Zeit weggelassen); im Modus „Befehl dekodieren“ den eingefügten Befehl als `input`. Das Popover nennt zuerst, was der Link enthält, und bietet dann „Link kopieren“ und, sofern der Browser eines bietet, das Teilen-Menü an; die Adresse der Seite bleibt unverändert.

Schnittstelle und Filter nennen Schnittstellen und Hosts Ihres Netzwerks, daher ergänzt das Popover in beiden Modi einen Warnhinweis. Das Formular zum Erstellen enthält kein Secret; das Feld zum Dekodieren nimmt beliebigen Text an, daher wird das Feld, bevor ein Link angeboten wird, nach Zugangsdaten durchsucht, die FortiOS oder ein Standard definiert: eine `set`-Zeile einer Einstellung, die in der [CLI-Referenz von FortiOS 7.6.8](https://docs.fortinet.com/document/fortigate/7.6.8/cli-reference/305883427/config-vpn-ipsec-phase1-interface) einen Passworttyp hat (`psksecret`, `password`, `passwd`, `secret`, `key`, `auth-pwd` und die übrigen; abgerufen am 01.11.2026), oder der `name` einer SNMP-Community ([RFC 1157](https://www.rfc-editor.org/rfc/rfc1157), Abschnitt 3.2.5), jeder `ENC`-Wert (das Advisory [FG-IR-19-007](https://www.fortiguard.com/psirt/FG-IR-19-007) von Fortinet, abgerufen am 01.11.2026, hält zu solchen Daten, die dort veröffentlicht werden, wo andere sie lesen können, fest: „should currently be considered "easy to decrypt"“), ein Paar `psksecret=` oder `password=` mit denselben Namen auf einer Direktivenzeile, ein privater Schlüssel im PEM-Format ([RFC 7468](https://www.rfc-editor.org/rfc/rfc7468)), ein JWT ([RFC 7519](https://www.rfc-editor.org/rfc/rfc7519)), eine Zeile `Authorization` ([RFC 9110](https://www.rfc-editor.org/rfc/rfc9110), Abschnitt 11.6.2), ein Passwort in einer URL oder eine AWS-Zugriffsschlüssel-ID. Findet sich eines davon, gibt es keinen Link: Das Popover nennt die Zeile, und Sie setzen einen Platzhalter an seine Stelle und wählen die Schaltfläche erneut; so teilen Sie genau das, was Sie gewählt haben (in einem eingefügten Feld wird nie ein Wert ersetzt, denn das würde ändern, was gesendet wird). Ein Wert, dessen Name nur nach einem Secret aussieht, verhindert den Link nicht; das Popover nennt den ersten solchen Wert.

Laut [RFC 3986](https://www.rfc-editor.org/rfc/rfc3986) (Abschnitt 3.5, abgerufen am 01.11.2026) ist das Fragment „separated from the rest of the URI prior to a dereference“, also vor der Dereferenzierung vom Rest der URI getrennt; daher wird, was nach dem `#` folgt, beim Öffnen des Links nicht an den Server gesendet. Es bleibt in der Adressleiste und im Verlauf dessen, der den Link öffnet, und wer den Link hat, kann es lesen.

- **Länge.** Insgesamt höchstens 16.384 Zeichen, die Grenze, die die Website für jeden Wert nach dem `#` setzt; ist der geteilte Inhalt länger, gibt es keinen Link, und das Popover nennt seine Länge.
- **Öffnen eines Links.** Der Modus des Absenders öffnet sich und seine Felder werden gefüllt (die des anderen Modus behalten ihre Werte), und die Seite erstellt oder dekodiert wie bei der Eingabe; es wird nichts mitgeschnitten oder ausgeführt. Ein Link, der beide Modi vermischt, eine Stufe, ein Protokoll oder einen Zeitstempel enthält, die das Formular nicht anbietet, oder eine Anzahl, die keine ganze Zahl ist, führt dazu, dass der ganze Link ignoriert wird. Danach verschwinden die Werte sofort aus der Adresse der Seite, ohne dass eine Anfrage gesendet wird; ein Neuladen oder die Schaltfläche „Teilen“ der Seite überträgt daher nichts.
