## Was das Tool tut

Das Tool macht aus der veröffentlichten Firewall-Referenz von F5 für Customer Edge (CE) eine einsatzfähige Zulassungsliste. Sie fügen den Inhalt der herunterladbaren Datei von F5 mit IP-Adressen und Domains ein (F5 veröffentlicht sie genau für diese Art der Automatisierung) und wählen Ihren Site-Typ; das Tool parst die Datei zu einer nach Zweck gegliederten, deduplizierten Zulassungsliste: Registrierung und Updates, Verbindung zu den Regional Edges, F5-Domains, Feeds für Reputation und Klassifizierung, Container-Registries, DNS und NTP, gefiltert nach dem gewählten Site-Typ. Dazu liefert es die Port- und Protokollmatrix, optionale Site-to-Site-Regeln, einen schlichten Text für den Firewall-Antrag, den Sie einem Netzwerkteam übergeben können, und ein Prüfskript für die CE-Seite. Alles läuft in Ihrem Browser.

## Warum das Tool parst, statt eine Liste mitzuliefern

Das eine echte Risiko jeder Firewall-Zulassungsliste ist, dass sie veraltet: IP-Bereiche und Domains ändern sich, und eine fest kodierte Liste verrottet in dem Moment, in dem F5 sie aktualisiert. F5 selbst warnt, dass sich die IP-Adressen ohne Ankündigung ändern können und dass Freigaben auf Domainbasis die bevorzugte Methode sind. Deshalb liefert das Tool nie eine eigene Kopie der Liste mit. Es parst die Datei, die Sie einfügen, und zeigt immer eine Herkunftszeile, die genau angibt, was es gelesen hat. Aktualisiert F5 die Datei, fügen Sie die neue ein, und die Ausgabe aktualisiert sich mit.

## Secure Mesh v2 oder Legacy

F5 teilt die Anforderungen auf zwei Site-Generationen auf. Der Workflow für Secure Mesh Site v2 verwendet eine einzige Wildcard-Domain im Besitz von F5 (oder eine FQDN-Liste, falls Ihre Firewall keine Wildcards unterstützt) und eine kleine Menge an IP-Adressen für die Registrierung. Legacy-CE-Sites verwenden eine lange Liste von IP-Bereichen und einen breiteren Satz an Domains, der Registries von Drittanbietern einschließt. Die Auswahl des Site-Typs filtert die geparsten Einträge auf die Generation, die Sie bereitstellen, sodass Sie keine Bereiche freigeben, die Sie nicht brauchen. Einträge, die für beide gelten (DNS, NTP und die gemeinsamen SaaS-Bereiche), sind immer enthalten.

## Die Portmatrix und die Site-to-Site-Regeln

Die Port- und Protokollmatrix ist aus der Referenz übernommen: Registrierung und Updates auf TCP 443, Verbindung zu den Regional Edges auf TCP 80 und 443 mit optionalem IPsec auf UDP 4500 (SSL-Tunneling wird als Fallback unterstützt) und NTP zum RE auf UDP 123, das von F5 bereitgestellte DNS auf TCP/UDP 53 und das von F5 bereitgestellte NTP auf UDP 123. Port 65500 ist für den lokalen Zugriff auf Oberfläche und API reserviert und keine Egress-Regel. Die optionalen Regelblöcke decken Cluster mit mehreren Knoten ab, Site Mesh Group (IPsec: UDP 500, UDP 4500 und ESP), DC Cluster Group (IP-in-IP auf UDP 6080) und AWS Cloud Connect (GRE, IP-Protokoll 47).

## Prüfen

Das erzeugte Skript ruft für jede Domain Ihrer Zulassungsliste den Serviceability-Befehl curl-host des CE auf, nach der von F5 dokumentierten Methode zur Fehlersuche bei der Registrierung. So können Sie vom Knoten selbst aus bestätigen, dass jeder Endpunkt erreichbar ist, bevor Sie ein Ticket eröffnen.

## Ergebnisse teilen

Unter der Herkunftszeile erzeugt **Ergebnisse teilen** einen Link auf diese Seite, und zwar nur, wenn Sie die Schaltfläche wählen und sobald die Seite die Datei geparst hat. Der Link enthält nach dem `#` die Datei so, wie eingefügt, und den gewählten Site-Typ. Das Popover nennt zuerst, was der Link enthält, und bietet dann „Link kopieren“ und, sofern der Browser eines bietet, das Teilen-Menü an; die Adresse der Seite bleibt unverändert. Die Datei von F5 selbst ([ips-domains.txt](https://docs.cloud.f5.com/docs-v2/downloads/multi-cloud-network-connect/reference/ce-ip-dom-ref/ips-domains.txt), 6.970 Zeichen beim Abruf am 01.11.2026) passt in einen Link; eine für eine einzelne Site bearbeitete Kopie kann deren eigene Adressen und Hosts nennen, und das Popover bittet Sie, sie zu prüfen. Bevor ein Link angeboten wird, wird der Text nach Zugangsdaten durchsucht, die ein Standard definiert: ein privater Schlüssel im PEM-Format, eine Zeile `Authorization` oder `Proxy-Authorization` mit beliebigem Schema ([RFC 9110](https://www.rfc-editor.org/rfc/rfc9110), Abschnitte 11.6.2 und 11.7.2: Der Wert „consists of credentials“), eine Zeile `Cookie` oder `Set-Cookie` mit einem Wert ([RFC 6265](https://www.rfc-editor.org/rfc/rfc6265), Abschnitt 8.4: Server „commonly store a nonce (or "session identifier") in a cookie“), ein JWT ([RFC 7519](https://www.rfc-editor.org/rfc/rfc7519), Abschnitt 1), ein Passwort in einer URL ([RFC 3986](https://www.rfc-editor.org/rfc/rfc3986), Abschnitt 3.2.1), eine AWS-Zugriffsschlüssel-ID oder ein `ENC`-Wert von FortiOS, dazu zwei Dinge, die das Schema von F5 Distributed Cloud selbst definiert: ein Secret vom Typ SecretType, also eine URL in `clear_secret_info` oder ein Ort in `blindfold_secret_info` (die [XC-API-Referenz](https://docs.cloud.f5.com/docs-v2/api/views-http-loadbalancer): „SecretType is used in an object to indicate a sensitive/confidential field“), und ein Matcher für den Header `Authorization` mit literalem Wert; alle abgerufen am 01.11.2026. Findet sich eines davon, gibt es keinen Link: Das Popover nennt die Zeile, und Sie setzen einen Platzhalter an seine Stelle und wählen die Schaltfläche erneut. Ein Wert, dessen Name nur nach einem Secret aussieht (ein JSON-Member `token`, ein `token=` in einer Query, ein Matcher für `X-Api-Key` oder ein Cookie), blockiert den Link nicht; das Popover nennt den ersten solchen Wert, damit Sie ihn prüfen können.

Laut [RFC 3986](https://www.rfc-editor.org/rfc/rfc3986) (Abschnitt 3.5, abgerufen am 01.11.2026) ist das Fragment „separated from the rest of the URI prior to a dereference“, also vor der Dereferenzierung vom Rest der URI getrennt; daher wird, was nach dem `#` folgt, beim Öffnen des Links nicht an den Server gesendet. Es bleibt in der Adressleiste und im Verlauf dessen, der den Link öffnet, und wer den Link hat, kann es lesen.

- **Länge.** Insgesamt höchstens 16.384 Zeichen, die Grenze, die die Website für jeden Wert nach dem `#` setzt; ist der geteilte Inhalt länger, gibt es keinen Link, und das Popover nennt seine Länge.
- **Öffnen eines Links.** Die Datei füllt das Feld wie beim Einfügen, der Site-Typ wird ausgewählt, und die Seite erstellt die Zulassungsliste. Ein Link ohne Site-Typ öffnet sich mit „Beide“. Danach verschwinden die Werte sofort aus der Adresse der Seite, ohne dass eine Anfrage gesendet wird; ein Neuladen oder die Schaltfläche „Teilen“ der Seite überträgt daher nichts.
