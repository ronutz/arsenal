O passo a passo recebe uma lista de 2 a 16 números e executa a estratégia escolhida uma decisão visível por vez. Cada passo mostra o estado do array com os índices tocados destacados, o tipo do passo (comparação, troca, escrita, nota) e uma linha de motivo para o movimento - a invariante que o algoritmo está protegendo. Os contadores no final são o ponto: rode a mesma lista em várias estratégias, ou aumente a lista, e observe como comparações e escritas escalam. Essa curva de escala é o Big-O tornado concreto, como [o primer de algoritmos](/learn/what-is-an-algorithm) desenvolve.

Dois comportamentos didáticos são preservados de propósito. O bubble sort carrega a clássica saída antecipada: entregue uma lista já ordenada e ele detecta o passe limpo e para após uma varredura linear. O quicksort usa a forma comum de ensino - partição de Lomuto com o último elemento como pivô - o que significa que uma lista já ordenada o empurra para o pior caso O(n²); cole uma e veja os contadores explodirem. Tudo roda localmente, a saída passa por checagem de invariante de ordenação a cada execução, e o mesmo motor é chamável pela API do site com um corpo JSON de `{"text": "5 3 8 1", "strategy": "merge"}`.

## Compartilhar resultado

Acima da lista de passos, o botão **Compartilhar resultado** cria um link para esta página, só quando você clica, que leva os números como foram digitados e a estratégia depois do `#`, assim que a página percorre os passos; os passos não vão, porque a página os recalcula exatamente. A estratégia vai sempre, então um link antigo mantém o sentido se o padrão mudar. O popover diz primeiro o que o link leva e então oferece Copiar link e, onde o navegador tiver, a tela de compartilhamento do sistema; o endereço da página não muda.

A [RFC 3986](https://www.rfc-editor.org/rfc/rfc3986) (seção 3.5, lida em 2026-11-01) diz que o fragmento é "separated from the rest of the URI prior to a dereference" (separado do resto do URI antes de o recurso ser buscado), então o que vem depois do `#` não é enviado ao servidor quando o link é aberto; fica na barra de endereço e no histórico de quem abre, e qualquer pessoa com o link consegue lê-lo.

- **Ao abrir um link.** Os números preenchem a caixa e a estratégia é escolhida como você faria, e a página percorre os passos. Uma estratégia desconhecida faz o link ser ignorado. Os valores então saem do endereço da página na hora, sem nenhuma requisição, então recarregar a página ou usar o botão Compartilhar da própria página não leva nada.
