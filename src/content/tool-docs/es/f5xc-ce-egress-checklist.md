## Qué hace

Esta herramienta convierte la referencia de firewall para Customer Edge (CE) que publica F5 en una lista de permitidos lista para usar. Pegas el contenido del archivo de direcciones IP y dominios que F5 ofrece para descargar (F5 lo publica justo para este tipo de automatización), eliges tu tipo de sitio y la herramienta lo analiza y lo convierte en una lista de permitidos organizada por propósito y sin duplicados (registro y actualizaciones, conectividad con los Regional Edge, dominios de F5, fuentes de reputación y clasificación, registros de contenedores, DNS y NTP), filtrada por el tipo de sitio que elegiste. También te da la matriz de puertos y protocolos, reglas opcionales de sitio a sitio, un texto plano de solicitud de firewall que puedes entregar a un equipo de red y un script de verificación para el lado del CE. Todo se ejecuta en tu navegador.

## Por qué analiza en lugar de listar

El único riesgo real de cualquier lista de permitidos de firewall es que se quede desactualizada: los rangos IP y los dominios cambian, y una lista fijada en el código caduca en cuanto F5 la actualiza. El propio F5 advierte que las direcciones IP pueden cambiar sin previo aviso y que los permisos basados en dominios son el método preferido. Por eso esta herramienta nunca trae su propia copia de la lista. Analiza el archivo que pegas y siempre muestra una línea de procedencia que indica exactamente qué leyó. Cuando F5 actualiza el archivo, pegas el nuevo y el resultado se actualiza con él.

## Secure Mesh v2 frente a Legacy

F5 divide los requisitos en dos generaciones de sitio. El flujo de Secure Mesh Site v2 usa un único dominio comodín propiedad de F5 (o una lista de FQDN si tu firewall no admite comodines) y un conjunto pequeño de direcciones IP de registro. Los sitios CE Legacy usan una lista grande de rangos IP y un conjunto de dominios más amplio, que incluye registros de terceros. El selector de tipo de sitio filtra las entradas analizadas según la generación que estás desplegando, para que no permitas rangos que no necesitas. Las entradas que se aplican a ambas (DNS, NTP y los rangos SaaS compartidos) se incluyen siempre.

## La matriz de puertos y las reglas de sitio a sitio

La matriz de puertos y protocolos se transcribe de la referencia: registro y actualizaciones en TCP 443, conectividad con los Regional Edge en TCP 80 y 443 con IPsec opcional en UDP 4500 (se admite el túnel SSL como alternativa) y el NTP del RE en UDP 123, el DNS que proporciona F5 en TCP/UDP 53 y el NTP que proporciona F5 en UDP 123. El puerto 65500 está reservado para el acceso local a la UI y a la API, y no es una regla de salida. Los bloques de reglas opcionales cubren los clústeres de varios nodos, Site Mesh Group (IPsec: UDP 500, UDP 4500 y ESP), DC Cluster Group (IP-in-IP en UDP 6080) y AWS Cloud Connect (GRE, protocolo IP 47).

## Verificación

El script generado ejecuta el comando curl-host de serviceability del CE contra cada dominio de tu lista de permitidos, siguiendo el método de solución de problemas de registro que documenta F5, para que puedas confirmar desde el propio nodo que cada endpoint es alcanzable antes de abrir un ticket.

## Compartir resultados

Debajo de la línea de procedencia, **Compartir resultados** genera un enlace a esta página, solo cuando lo presionas, que lleva después del `#` el archivo tal como se pegó y el tipo de sitio que elegiste, una vez que la página ha analizado el archivo. Su ventana emergente dice primero qué lleva el enlace y después ofrece Copiar enlace y, si el navegador lo tiene, el menú Compartir del sistema; la dirección de la página no cambia. El archivo del propio F5 ([ips-domains.txt](https://docs.cloud.f5.com/docs-v2/downloads/multi-cloud-network-connect/reference/ce-ip-dom-ref/ips-domains.txt), 6970 caracteres al consultarlo el 2026-11-01) cabe en un enlace; una copia editada para un sitio concreto puede nombrar las direcciones y los hosts propios de ese sitio, y la ventana emergente te pide que la revises. Antes de ofrecer un enlace, se busca en el texto una credencial definida por un estándar: una clave privada PEM, una línea `Authorization` o `Proxy-Authorization` con cualquier esquema ([RFC 9110](https://www.rfc-editor.org/rfc/rfc9110), secciones 11.6.2 y 11.7.2: el valor “consists of credentials”, consiste en credenciales), una línea `Cookie` o `Set-Cookie` con valor ([RFC 6265](https://www.rfc-editor.org/rfc/rfc6265), sección 8.4: los servidores “commonly store a nonce (or ‘session identifier’) in a cookie”, suelen guardar en una cookie un nonce o identificador de sesión), un JWT ([RFC 7519](https://www.rfc-editor.org/rfc/rfc7519), sección 1), una contraseña en una URL ([RFC 3986](https://www.rfc-editor.org/rfc/rfc3986), sección 3.2.1), un ID de clave de acceso de AWS o un valor `ENC` de FortiOS, y dos cosas que define el propio esquema de F5 Distributed Cloud: un secreto SecretType, es decir, una URL `clear_secret_info` o una ubicación `blindfold_secret_info` (la [referencia de la API de XC](https://docs.cloud.f5.com/docs-v2/api/views-http-loadbalancer): “SecretType is used in an object to indicate a sensitive/confidential field”, se usa en un objeto para indicar un campo sensible o confidencial), y un comparador del encabezado `Authorization` con un valor literal; todos consultados el 2026-11-01. Si aparece uno, no hay enlace: la ventana emergente indica su línea, y tú lo sustituyes por un marcador de posición y vuelves a presionar. Un valor cuyo nombre solo parece el de un secreto (un miembro JSON `token`, un `token=` en una cadena de consulta, un comparador de `X-Api-Key` o de cookie) no bloquea el enlace; la ventana emergente indica el primero para que puedas revisarlo.

Según el [RFC 3986](https://www.rfc-editor.org/rfc/rfc3986) (sección 3.5, consultado el 2026-11-01), el fragmento queda “separated from the rest of the URI prior to a dereference” (separado del resto del URI antes de resolverlo), así que lo que va después del `#` no se envía al servidor cuando se abre el enlace; se queda en la barra de direcciones y en el historial de quien lo abra, y cualquiera que tenga el enlace puede leerlo.

- **Longitud.** Como máximo 16.384 caracteres en total, el límite que el sitio aplica a todo valor después del `#`; si lo compartido es más largo, no hay enlace, y la ventana emergente indica su longitud.
- **Al abrir un enlace.** El archivo rellena el cuadro como lo haría un pegado, se selecciona el tipo de sitio y la página genera la lista de permitidos. Un enlace sin tipo de sitio se abre con Ambos. Después, los valores salen de la dirección de la página al instante, sin ninguna solicitud, así que al recargar, o con el propio botón Compartir de la página, no se lleva nada.
